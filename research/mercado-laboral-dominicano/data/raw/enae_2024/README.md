# ENAE 2024: fuente contextual

`base_de_datos_general_ENAE_2024.xlsx` es la base general oficial de la Encuesta Nacional de Actividad Económica 2024.

Se conserva como contexto para el apartado laboral del artículo, pero no entra en la estimación de homogamia: ENAE no identifica parejas convivientes dentro de hogares y, por tanto, no puede reemplazar Censo o ENHOGAR para medir emparejamiento educativo.
