# Datos locales de la tesis monetaria

Estos archivos son copias de trabajo tomadas de `C:\Users\leona\Archivo_Local\Documentos\tesis_monetaria_rd` para que las figuras del módulo MIPYME sean reproducibles dentro del repositorio:

- `enmipymes_r.csv`: microdatos procesados de ENMIPYMES, con factor de expansión y variables de formalidad, tamaño, educación, ingresos, empleo y barreras de crédito;
- `sb_carteras_creditos_sectores_economicos.csv`: cartera de crédito por sector económico;
- `sb_carteras_creditos_localidad.csv`: cartera de crédito por localidad.

Las cifras de la matriz de problemas de financiamiento usan el factor de expansión `factor_exp` y reportan porcentajes ponderados por grupo de tamaño y formalidad. No se interpretan como efectos causales.

La copia se mantiene separada de los datos oficiales descargados para dejar clara su procedencia local y evitar presentar archivos de tesis como si fueran una publicación estadística institucional.
