# Fuentes

El Informe Estadístico 2024 del CNZFE se consulta en el [archivo oficial de informes anuales](https://cnzfe.gob.do/transparencia/publicaciones-oficiales/informes-estadisticos-anuales/).

La copia del PDF no se distribuye en este repositorio: su página 2 contiene una nota de confidencialidad y restricciones de reproducción, aunque el organismo lo ofrece públicamente. Una copia local con el nombre `cnzfe_informe_estadistico_2024.pdf` queda excluida de Git. El build del sitio no depende de ese archivo.
